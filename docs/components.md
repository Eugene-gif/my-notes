# Компоненты

Компоненты лежат непосредственно в `src/components`: каждый `Name.vue` содержит шаблон, а при необходимости — `<script setup lang="ts">` и `<style scoped>`. Общие цвета, сброс и оформление документа — в `src/assets/styles/style.css`; правила карточек и элементов интерфейса принадлежат самим компонентам. Пользовательский текст выводится через интерполяцию Vue. Все интерфейсные SVG находятся в шаблонах компонентов Icon*.vue в `src/assets/icons`; цвет наследуется через currentColor, размер задаёт родительский класс или атрибуты SVG.

TaskCard использует useTaskExpansion: высота плавно меняется между 64 px и полной высотой текста. Повторное нажатие разворачивает анимацию с текущей высоты; при prefers-reduced-motion переход выполняется сразу. Анимация освобождается после завершения и при демонтаже.

NotesWorkspace анимирует смену содержимого раздела, сохраняя шапку на месте. При prefers-reduced-motion переход выполняется сразу.

ActionMenu через useMenu выбирает открытие вниз или вверх по свободному месту на экране. Если меню целиком не помещается с обеих сторон, используется более свободная сторона и внутренняя прокрутка. Положение обновляется при прокрутке, изменении размеров меню и видимой области экрана.

Props icon и align задают иконку кнопки и сторону привязки меню. В хедере слева находится меню пользователя: «Сменить тему» переключает светлую и тёмную темы; «Регистрация» и «Войти» пока остаются заглушками. IconControl поддерживает иконку user. Настройка палитры описана в [themes.md](themes.md).

## PWA

Пункт «Установить приложение» в меню пользователя вызывает системный запрос установки либо показывает инструкцию. В установленном окне он скрыт. Иконка смены темы показывает солнце в тёмном режиме и луну в светлом. EntryForm через useUnsavedChanges регистрирует изменённый черновик до демонтажа формы. AppUpdatePrompt не использует кратковременный Notice; его состояние сохраняется до выбора пользователя.

## Уведомления

```ts
const notices = useNoticesStore();
notices.show('Сохранено.', 'success');
notices.show('Не удалось сохранить.', 'error');
notices.show('Операция выполняется…', 'info', { duration: 0, closable: true });
notices.close();
```

Статусы: success, error, info. По умолчанию duration = 2000 мс и closable = true; duration = 0 отключает автозакрытие. Отсчёт начинается после показа. Новое сообщение заменяет предыдущее. Ошибки имеют role=alert, остальные сообщения — role=status. Текст безопасно выводится как текст. Уведомление использует Popover API и перемещается внутрь открытого диалога. Если диалог закрывается, новый нотис ожидает завершения закрытия. Перенос уже видимого нотиса не запускает анимацию появления повторно. Таймеры и MutationObserver очищаются при демонтаже. Цвета настраиваются переменными --notice-* внутри Notice.vue и общей палитрой style.css.

Компонентные тесты повторяют эту структуру в `tests/src/components`, тесты иконок — в `tests/src/assets/icons`. Архитектурные правила: [architecture.md](architecture.md).
