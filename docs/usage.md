# Использование My notes

## Записи и навигация

На главной или в папке откройте меню → «Добавить», затем выберите папку, заметку или перечень. Пустое название заменяется датой и московским временем. Папки могут содержать другие папки, заметки и перечни.

Карточка открывает раздел. Хлебные крошки и кнопка «Назад» возвращают к предкам; если путь не помещается, «…» открывает полный путь. Раздел имеет собственный URL; можно использовать назад/вперёд браузера. Последний открытый раздел сохраняется для следующего запуска с главной.

## Задачи и заметки

В перечне две кнопки «Добавить задачу»: верхняя вставляет задачу в начало, нижняя — в конец. Текст может быть многострочным. Нажатие на задачу циклически переключает статусы: без статуса → в процессе → выполнено. Длинную задачу можно развернуть. Меню карточки позволяет выбрать, изменить или удалить задачу.

Заметка открывается для чтения. «Изменить» включает редактор; «Сохранить» применяет изменения, «Отмена» отбрасывает черновик. Многострочное поле автоматически растёт, после достижения границы формы прокручивается внутри.

Удаление подтверждается в диалоге. Удаление папки включает вложенные записи; удаление перечня включает его задачи.

## Поиск, вид и групповые действия

Поиск выполняется через 300 мс после ввода, новый ввод отменяет предыдущий таймер. На главной и в папке ищет по всем записям и описаниям заметок; внутри перечня — только по его задачам. Совпадения подсвечиваются. Результат задачи открывает её перечень и подсвечивает карточку.

«Вид» выбирает список, две или три колонки. На узком экране число колонок уменьшается. В перечне всегда одна колонка; предпочтение для папок и главной сохраняется.

«Выбрать» включает групповое выделение карточек. Доступны выбор всех, удаление с подтверждением и групповой перенос. Во время выбора нажатие карточки не открывает её и не меняет статус задачи. «Отмена» или Escape завершают выбор.

## Перетаскивание

Мышью перетаскивайте за карточку, кроме меню и кнопки разворачивания. На сенсорном экране удержите карточку 300 мс перед переносом; обычный свайп прокручивает страницу. Края карточки вставляют элемент перед ней или после неё. В сетке учитываются левый/правый края.

Центр другой задачи меняет задачи местами. Центр папки предлагает перенос внутрь или обмен; центр перечня/заметки — допустимый обмен. Для группы доступен перенос, обмен — только для одного элемента. Порядок внутри группы сохраняется. Крошки позволяют перейти к другому разделу во время переноса при задержке над предком.

Задачи можно перемещать только в перечни. Папки, перечни и заметки — в папки или на главную. Перенос папки в себя или своего потомка запрещён. Escape отменяет жест или выбор действия после отпускания.

## Сохранение

Данные и настройки сохраняются в браузере. При успешной записи показывается зелёное уведомление; при отказе записи — ошибка, действие не применяется. Очистка данных сайта удалит заметки. Автоматической синхронизации устройств нет.
