# Темы

Пункт «Сменить тему» в меню пользователя переключает светлую и тёмную темы. По умолчанию используется светлая; выбор сохраняется в `notes-app__theme`. Если запись недоступна, переключение всё равно работает до перезагрузки, а уведомление сообщает об ошибке сохранения.

- `src/assets/styles/style.css` — светлая палитра и общие переменные `--color-*`.
- `src/assets/styles/themes.css` — тёмная палитра `--dark-theme-*` и её привязка к `--color-*` при `html[data-theme='dark']`.
- `workspaceStore` — состояние `theme`, восстановление и действие `toggleTheme()`.
- `useTheme` — наблюдение за темой с очисткой при демонтаже; `utils/theme.ts` — установка атрибута с проверкой доступности DOM.

Основные поверхности и синий акцент взяты за ориентир из [Lara Dark Blue в PrimeVue 3](https://v3.primevue.org/theming/). Цвета состояний адаптированы под карточки My notes; PrimeVue не подключается.

Чтобы изменить тёмную палитру, редактируйте значения `--dark-theme-*`. В компонентах используйте общие `--color-*`, чтобы одна разметка поддерживала обе темы. Новому цвету нужны светлое значение, тёмная переменная и соответствующая привязка. Для основных кнопок, отметок выбора и полей есть отдельные переменные: их текст и фон не зависят от цвета поверхности.

Тема применяется в `main.ts` до ожидания роутера и монтирования приложения. `color-scheme` согласует нативные элементы и полосы прокрутки с темой. При переносе на Nuxt клиентскую инициализацию следует вынести в плагин; для одинаковой темы на сервере и клиенте понадобится передавать предпочтение через cookie.
