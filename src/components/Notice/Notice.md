# Notice

Настраиваемое уведомление сверху по центру экрана. По умолчанию показывается 2 секунды, затем плавно исчезает за 160 мс. Крестик позволяет закрыть уведомление раньше. Компонент не перемещает фокус при появлении и не перекрывает взаимодействие с содержимым страницы, кроме своей кнопки закрытия.

## Использование

```js
import { createNotice } from './Notice';

const notice = createNotice(); // Вызывать после появления document.body.
notice.success('Папка создана.');
notice.error('Не удалось сохранить изменения.');
notice.info('Изменения отменены.');

notice.show({
  message: 'Настройки сохранены.',
  status: 'success',
  duration: 2000,
  closable: true,
});
```

У одного экземпляра одновременно отображается одно уведомление. Новое заменяет предыдущее и начинает отсчёт заново; старые таймеры отменяются. Текст вставляется через `textContent`, поэтому HTML в сообщении остаётся обычным текстом.

## Статусы

| Значение | Назначение | Иконка | Цвет |
| --- | --- | --- | --- |
| `success` | Успешное добавление, изменение, сохранение, удаление, перенос | Галочка в кругу | Спокойный зелёный `#527c63` |
| `error` | Действие не удалось выполнить или сохранить | Крест в кругу | Приглушённый красный `#aa6268` |
| `info` | Информация, отмена, подсказка | Перевёрнутый восклицательный знак в кругу | Спокойный синий `#587b9e` |

Статус описывает результат: успешное удаление тоже зелёное. Ошибки объявляются вспомогательным технологиям как `alert`, остальные сообщения — как `status`. Движение отключается при `prefers-reduced-motion`.

## Настройки

Параметры `createNotice(options)` задают значения по умолчанию:

| Параметр | По умолчанию | Описание |
| --- | --- | --- |
| `duration` | `2000` | Время показа в миллисекундах. `0` отключает автозакрытие. |
| `closable` | `true` | Показывать крестик закрытия. |
| `top` | `'20px'` | Отступ сверху, строка с CSS-размером. |
| `width` | `'460px'` | Максимальная ширина; на узком экране остаются боковые отступы 16 px. |
| `container` | `document.body` | Родитель уведомления. Контейнер должен быть подключён к документу. |

Метод `show({ message, status, duration, closable })` переопределяет длительность и наличие крестика для одного сообщения. Статус по умолчанию — `info`. Неизвестный статус, отрицательная или нечисловая длительность вызывают исключение.

```js
const notice = createNotice({ duration: 3000, top: '24px', width: '520px' });
notice.info('Долгая операция…', { duration: 0 });
notice.success('Готово.', { duration: 2000 });
notice.close();   // Закрыть текущее уведомление с анимацией.
notice.destroy(); // Отменить таймеры и удалить компонент при демонтаже страницы.
```

Вызов `show` после `destroy` вызывает исключение. Для дальнейших уведомлений создайте новый экземпляр.

## Стилизация

Значения палитры и переменные `.notice-host` определяются в общем `src/style.css`, а `Notice.css` только использует их: `--notice-success`, `--notice-error`, `--notice-info` для иконок; соответствующие `-bg` и `-border` для фона и рамки. Например:

```css
.notice-host {
  --notice-info: #587b9e;
  --notice-info-bg: #f3f7fb;
  --notice-info-border: #d5e1ed;
}
```

Иконки встроены в компонент как SVG. Карточка имеет скругление 12 px и лёгкую тень. В браузерах с Popover API используется верхний слой для показа поверх диалогов; в остальных — фиксированное позиционирование.

## Подключение в Todo

Успешные уведомления отправляются после записи изменений в локальное хранилище. Если запись не удалась, показывается ошибка вместо успеха. Сообщения включают создание папок, перечней, заметок и задач; редактирование и переименование; выполнение задачи; удаление и очистку; перестановку, обмен и перенос; сохранение сетки. Подсказки и отмена используют `info`.
