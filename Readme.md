## Описание:
Проект представляет из себя простой список дел на нативном JS

Полный функционал, устройство кода и контекст для новых разработчиков и ИИ-агентов: [Docs.md](Docs.md).

### Папки, перечни и заметки

- На главной меню содержит «Добавить», «Выбрать» (если есть элементы), «Поиск», «Вид». Пункт «Добавить» открывает модальное окно с тремя кнопками и иконками: папка, заметка, перечень. Кнопки расположены друг под другом; выбор открывает соответствующую форму создания. Подсказка о перетаскивании на главной скрыта.
- Поиск обновляет результаты через 300 мс после последнего ввода; новый ввод отменяет предыдущий таймер. После закрытия окна отложенный поиск не выполняется.
- Меню «Добавить» → «Добавить папку» добавляет папку в текущий раздел. Без названия используется дата и московское время, например `04.10.2026 в 19:40`.
- Меню «Добавить» → «Добавить перечень» создаёт именованный список задач на главной или в папке. Внутри перечня задачи расположены строго в одну колонку; кнопки «+» и пункта «Вид» нет. Меню: «Выбрать», «Переименовать перечень», «Поиск», «Удалить перечень». Поиск в этом разделе проверяет только задачи текущего перечня.
- Меню «Добавить» → «Добавить заметку» создаёт заметку с названием и обычным многострочным описанием. При открытии видны заголовок и текст без полей ввода. Кнопка «Изменить» справа сверху или пункт меню «Изменить заметку» открывают редактор. «Сохранить» применяет изменения и возвращает просмотр; «Отмена» отбрасывает черновик. Внутри заметки кнопка «+» скрыта. Удаление заметки требует подтверждения и находится последним пунктом меню.
- Поле описания заметки растёт по тексту от 180 px до 100dvh и уменьшается при удалении текста. Ручное растягивание отключено. Внутренняя прокрутка появляется только при превышении максимальной высоты; ширина и высота экрана учитываются автоматически.
- Пункт «Вид» в верхнем меню открывает окно с выбором списка, двух или трёх колонок. Выбор сохраняется в браузере.
- Пункт «Поиск» открывает окно поиска по названиям всех элементов и описаниям заметок. Совпадения подсвечиваются жёлтым. Прокручивается только список результатов; окно ограничено высотой экрана с отступами 20 px сверху и снизу. Нажатие на результат открывает его с правильным путём; для задачи открывается её перечень и подсвечивается сама задача.
- Пункт «Выбрать» включает выбор нескольких карточек нажатием. Переходы и выполнение задач в этом режиме отключены. Доступны «Выбрать все», удаление выбранных с подтверждением и групповой перенос за карточку отмеченной задачи или иконку другого отмеченного элемента. «Отмена» или Escape завершают выделение.
- Нажатие на папку или перечень открывает его содержимое. Путь сверху позволяет вернуться к родительской папке или на главную.
- Главная обозначена иконкой `home`. Если полный путь не помещается в одну строку, отображается «домик › … › текущий элемент»; «…» открывает полный путь для возврата к любому предку. Родительские папки отображаются открытыми непустыми; только текущая пустая папка использует `folder-empty-open`. Для карточки пустой папки используется `folder-empty`. Папка с пустым перечнем или заметкой считается непустой.
- Внутри папки или перечня верхнее меню «…» позволяет переименовать или удалить текущий элемент. Пункт «Открыть» остаётся только в меню карточек.
- В перечне две кнопки «+ Добавить задачу» высотой 40 px открывают создание задачи: верхняя добавляет в начало, нижняя — в конец. Многострочное поле растёт от 180 px до свободного места в окне, затем прокручивается внутри. Меню каждой задачи позволяет выбрать её для группового переноса или удаления. Для удаления нескольких элементов используйте «Выбрать». Удаление папки включает все вложенные перечни и задачи.
- Высота карточек задач — 80 px, остальных элементов — 100 px, кнопок добавления задачи — 40 px. Текст задачи сохраняет переносы и занимает до трёх строк, текст и галочка выровнены сверху. Длинные заголовки остальных элементов сокращаются до одной строки с многоточием, описания — до двух строк с плавным затуханием при переполнении.
- Окно создания заметки ограничено экраном с отступами 20 px сверху и снизу. Описание растёт до свободного места внутри окна, после чего прокручивается только поле; кнопки остаются видимыми.
- Перетащите задачу за любую область карточки, кроме кнопки меню, папку, перечень или заметку — тоже за любую область карточки, кроме меню. Перенос работает мышью и пальцем. Папка при наведении больше не открывается: после отпускания на ней выбирается «Переместить в папку» или «Поменять местами». Для группы доступен перенос, обмен — для одного элемента. «Отмена», Escape или нажатие вне меню отменяют выбор без изменения данных. Задачи можно перемещать только между перечнями; папки, перечни и заметки — в папки или на главную. Заметка не принимает вложенные элементы.
- В сетке из двух или трёх колонок края карточки меняют порядок, а линия вставки отображается сбоку. В одну колонку используются верхний и нижний края и горизонтальная линия. Центр папки открывает выбор переноса внутрь или обмена после отпускания; центр перечня и заметки — только обмен. При вставке группы её внутренний порядок сохраняется. Порядок сохраняется после перезагрузки.
- Нажатие на карточку задачи меняет её статус. У выполненной задачи появляется галочка; у остальных место для неё остаётся свободным. Меню «…» задачи содержит «Изменить» (открывает окно редактирования) и «Удалить». Перетаскивание и использование меню не меняют статус.
- Перенос задачи в центральную половину другой задачи меняет их местами, сохраняя позиции остальных задач. Подсветка «⇄ Поменять местами» отличает обмен от вставки: внешние четверти карточки по-прежнему вставляют перед ней или после неё. Обмен работает мышью и пальцем, в том числе между перечнями; результат сохраняется в браузере.
- Папка показывает число непосредственно вложенных элементов. Перечень показывает число задач и «Выполнено X/Y»: зелёная обводка означает, что выполнены все задачи, жёлтая — только часть. Пустые перечни имеют обычную рамку. Папки не подсвечиваются по выполнению задач.
- Задачи, папки, перечни, заметки с описаниями, текущий раздел и вид сетки сохраняются в браузере. При обновлении старые задачи группируются в перечни «Задачи» в прежних разделах, сохраняя текст, отметки и порядок.

### Уведомления

Результаты действий показываются сверху по центру на 2 секунды с крестиком закрытия. Успех — приглушённый зелёный, ошибка — красный, информация — синий. Новое сообщение заменяет предыдущее. Документация и настройки: [Notice](src/components/Notice/Notice.md).

### Сборка для продакшена
```
npm run build (yarn build)
```

Цвета и статические CSS-переменные собраны в `src/style.css`. Иконки и рамки перечней используют общий спокойный зелёный или умеренный жёлтый в зависимости от выполнения. Меню после переноса появляется у точки отпускания и ограничивается границами экрана. Клик или касание края карточки открывает элемент.
